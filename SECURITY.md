# Security

## Report a security problem privately

If you find a security problem in hYYa ink — a file that makes the app run code, leak data or
crash in a way someone could abuse, a way to read the AI key you saved, anything like that —
please tell us **privately** by e-mail at **[security@hyya.com](mailto:security@hyya.com)**, or
through the contact form at [hyya.com/#contact](https://hyya.com/#contact). In hYYa ink for
Android, **Settings → Help and more → Report a security issue** opens an e-mail to it.

**Please don't open a public issue for it.** Issues in this repository are public the moment
they are filed, and a problem described here before it is fixed puts every reader at risk.

Tell us, if you can:

- the device and system (for example: iPhone with iOS 26, a Mac with macOS 15, Android 15),
- the version of hYYa ink — it is shown on the app's page in the App Store or Google Play,
- what you did and what happened, and
- a sample file that shows it. A file you made up is best; please don't send anything private.

## What happens next

We read every report. We reproduce the problem, fix it in an update for each platform it
affects — Mac, iPad and iPhone, and Android — and tell you when the fix is out.

If a problem is being exploited, we also report it as EU law requires, and tell users what it
was and what to do: here, in the update's release notes and on hyya.com.

## Which versions get fixes

Fixes ship as updates through the App Store and Google Play. The newest version on each store is
the one that receives them, so keep automatic updates on.

## Security advisories

None so far. When there is one, it is listed here with its date, the platforms and versions it
affects, the version that fixes it, and what you can do until you update.
